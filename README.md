# DesktopPet · 芙瑞希雅 桌宠

一只会陪你干活的小桌宠：芙瑞希雅。
她待在桌面最上层，会根据你正在做的事，比如打字、画画、听歌、打游戏、截图、离开电脑，自动切换不同的动作，也可以戳一戳、拖来拖去。

原作：被困的芙瑞希雅

图片素材捏自 EmoteLab

## 下载

- [Freesia.exe](../../releases/latest/download/Freesia.exe)

下载后双击即可运行，无需安装。

- 系统要求：Windows 10 / 11
- 退出：先点一下桌宠，再按 **Alt + F4**

## 互动

- **点一下**：戳一戳，她会随机给你一个反应
- **按住拖动**：把她拖到屏幕任意位置
- **透明的地方**：鼠标会直接穿透过去，不会挡住你点后面的窗口

## 她会看你在做什么

| 你在做什么 | 她的反应 |
|---|---|
| 刚打开 | 打个招呼出场，然后进入待机 |
| 没在做特别的事 | 待机，过一阵子会换一个待机动作；偶尔还会来一段随机小动作 |
| 打字 | 陪你一起打字 |
| 画画 | 陪你一起画画（支持 PS、CSP、SAI、Krita 等常见画画软件） |
| 听音乐 | 跟着一起听歌（网易云、QQ 音乐、Spotify 等，后台播放也算） |
| 打游戏 | 陪你打游戏（Steam 等平台的游戏、原神等） |
| 截图 | 拿出相机咔嚓一下 |
| 离开电脑一会儿 | 睡着了；你一动鼠标或键盘她就醒 |
| 电量快没了 | 一直提醒你充电，插上电源后会开心地充个电 |

几件事同时发生时，她会优先回应更"要紧"的那件：
**戳一戳 > 截图 > 出场 > 低电量 > 打游戏 > 画画 > 打字 > 听音乐 > 睡觉 > 随机动作 > 待机**

### 打字和画画时的小情绪

| 心情 | 打字 | 画画 |
|---|---|---|
| 普通 | 正常打字 | 正常画画 |
| 生气 | 你打字飞快的时候 | 你疯狂按 Ctrl+Z 撤销的时候 |
| 疲倦 | 连续打字太久 | 连续画画太久 |

放慢速度或停止撤销，她很快就会消气；中途好好休息一会儿，疲倦也会消失。


## 隐私说明

为了知道你在做什么，桌宠会在后台运行一个小助手。它只看"有没有在打字""前台是什么软件""哪个软件在出声""剪贴板有没有新图片""电量多少"这类信息，不记录你按了什么键，不读取任何内容，也不联网。

## 常见问题

**杀毒软件报"键盘监控"：**
打字检测需要知道你有没有在按键，会被部分杀毒软件当成可疑行为。它只数按了几次，不记录内容，可以放心加入信任。

**某个软件 / 游戏没被识别：**
欢迎提 Issue 告诉我软件或游戏的名字。

**任务管理器里多了一个 powershell.exe：**
那就是上面说的小助手，桌宠关闭后会自动结束。
