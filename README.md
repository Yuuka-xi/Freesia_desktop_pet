# DesktopPet · 雷内 & 阿兰 桌宠

两只会陪你干活的 Windows 桌宠：**雷内·英戈德** 和 **阿兰·吉约丹**。
它们待在桌面最上层，会根据你正在做的事，比如打字、画画、听歌、打游戏、截图、离开电脑自动切换不同的动作，也可以戳一戳、拖来拖去。

虽然是两个分开的小桌宠，但是是主播技术力限制导致的，雷兰属性不拆不逆哦

雷雷兰兰来自原神枫丹支线任务水仙十字愿，压榨新鲜胎海水，水仙十字畅享新生！

## 互动

| 操作 | 效果 |
|---|---|
| 点一下 | 戳一戳，随机播放一个反应；连续点会换着反应 |
| 按住拖动 | 把桌宠拖到屏幕任意位置 |
| 透明的地方 | 鼠标会直接穿透到下面的窗口，不挡你点东西 |

## 它会看你在做什么

| 你在做什么 | 桌宠的反应 | 怎么判断 |
|---|---|---|
| 刚打开 | 播放出场动画 | — |
| 没在做特别的事 | 待机，每隔一段时间换一个待机动作；偶尔来一段随机小动作 | — |
| 打字 | 陪你打字 | 5 秒内按键 8 次以上；停手 5 秒后恢复 |
| 画画 | 陪你画画 | 前台是 Photoshop、Clip Studio Paint、SAI、Krita、MediBang、FireAlpaca、Illustrator、Aseprite |
| 听音乐 | 一起听歌 | 网易云、QQ 音乐、酷狗、酷我、Spotify、Apple Music、foobar2000、MusicBee、AIMP 正在出声（后台播放也算） |
| 打游戏 | 一起打游戏 | Steam / Epic / WeGame / EA / Ubisoft / GOG / Xbox / Riot 的游戏，原神、星穹铁道、绝区零等，或独占全屏程序 |
| 截图 | 拿出相机拍一下 | 剪贴板里出现新图片（Win+Shift+S、微信 / QQ 截图、Snipaste 复制等） |
| 离开电脑 5 分钟 | 睡着；一动鼠标或键盘就醒 | 系统记录的最后一次键鼠操作时间 |
| 电量低于 10% 且没插电 | 一直提醒你充电 | 系统电源状态（台式机不会触发） |
| 插上电源 | 播放一次充电动画 | 同上 |

同时满足多个条件时，按这个顺序优先显示：
**戳一戳 > 截图 > 出场 > 低电量 > 打游戏 > 画画 > 打字 > 听音乐 > 睡觉 > 随机动作 > 待机**

> 小提示：在画画软件里按 Ctrl+C 复制图片不会被当成截图，所以可以安心画画！

### 雷内的专属心情

雷内在打字和画画时会有三种状态：

| 心情 | 打字 | 画画 |
|---|---|---|
| 普通 | 正常速度打字 | 正常画画 |
| 生气 | 打字飞快（平均每秒 6 键以上） | 疯狂撤销（10 秒内 Ctrl+Z 5 次以上） |
| 疲倦 | 连续打字超过 30 分钟 | 连续画画超过 30 分钟 |

生气优先于疲倦；中途休息满 5 分钟，疲倦就会清零。

## 隐私说明

为了知道你在做什么，桌宠会在后台运行一个 PowerShell 小助手（`activity_monitor.ps1`），所有数据只在本机使用，不联网也不保存。

## 常见问题

杀毒软件报键盘监控：
打字检测用到了系统的全局键盘监听，会被部分杀毒软件当成可疑行为。它只统计按键次数，可以放心加入信任。

某个软件 / 游戏没被识别：
目前名单是固定在程序里的，欢迎提 Issue 告诉我软件或游戏的名字。

任务管理器里多了一个 powershell.exe：
那就是上面说的小助手，桌宠关闭后会自动结束。
